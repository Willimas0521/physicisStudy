④ 全反射

光从光密介质射向光疏介质，且入射角增大到某一值时，折射光完全消失，全部反射回原介质。

✅ 发生条件（缺一不可）：
  • ① 光从光密介质射向光疏介质（$n_1 > n_2$）；
  • ② 入射角 ≥ 临界角 $C$。
$$\sin C = \dfrac{n_2}{n_1} \quad (\text{当 } n_2 < n_1)$$

若从介质射入空气（$n_2 \approx 1$）：

$$\sin C = \dfrac{1}{n}$$

应用：光导纤维（光纤通信）、全反射棱镜、钻石璀璨光芒。

🔴 易错辨析（高频考点）：全反射的第一条件是"光从光密介质射向光疏介质"（$n_1 > n_2$）。若光从光疏介质射向光密介质（如空气→水、空气→玻璃），无论入射角多大，折射角始终小于入射角（$\theta_2 < \theta_1$），折射光永远存在，不可能发生全反射。
✅ 记忆口诀："密到疏"才可能全反射；"疏到密"永远不全反射。
例1：某玻璃的折射率 $n=1.5$，光从玻璃射向空气，求发生全反射的临界角 $C$。
解：$\sin C = \dfrac{1}{n} = \dfrac{1}{1.5} = 0.667$
$C = \arcsin(0.667) \approx \mathbf{41.8^\circ}$
答：入射角 ≥ 41.8° 时发生全反射。
