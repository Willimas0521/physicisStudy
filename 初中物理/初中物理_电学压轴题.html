📌 电学三大基础公式（贯穿所有压轴题）：
$$I = \dfrac{U}{R}\quad P = UI\quad Q = I^2Rt \ (\text{纯电阻})$$

1动态电路分析

含滑动变阻器的电路，当滑片移动时电阻变化，引起电流、电压、电功率的连锁变化。这是选择题、填空题的必考压轴题型。

核心方法：串反并同

以滑动变阻器 $R_{\text{滑}}$ 的阻值变化为"自变量"，分析其他用电器的物理量：

  • 串反：与 $R_{\text{滑}}$ 串联的用电器，其电流、电压、电功率变化方向与 $R_{\text{滑}}$ 相反（滑变变大则它变小）。
  • 并同：与 $R_{\text{滑}}$ 并联的用电器（通常指定值电阻 $R_0$），其电压变化方向与 $R_{\text{滑}}$ 相同。

典型模型：定值电阻 $R_0$ 与滑动变阻器 $R_{\text{滑}}$ 串联，电压表测 $R_0$ 两端电压

推导示例（串联电路，滑片右移使 $R_{\text{滑}}$ 变大）

总电阻 $R_{\text{总}} = R_0 + R_{\text{滑}} \uparrow\ \Rightarrow\ $ 电流 $I = \dfrac{U}{R_{\text{总}}} \downarrow$
$R_0$ 两端电压（电压表）：$U_0 = I R_0 \downarrow$（串反，与 $R_{\text{滑}}$ 变化相反）
$R_{\text{滑}}$ 两端电压：$U_{\text{滑}} = U - U_0 \uparrow$（并同，分压变大）
例：如上图，闭合开关，滑片 $P$ 向右移动（接入电阻变大），则电流表示数、电压表示数如何变化？$R_0$ 的实际功率如何变化？
答：电流表示数 变小；$R_0$ 与 $R_{\text{滑}}$ 串联，电压表测 $R_0$，$U_0 \downarrow$ 故电压表示数 变小。
$R_0$ 实际功率 $P_0 = I^2 R_0$，$I$ 变小 → $P_0$ 变小。

2电路故障判断

故障只有两类：短路（用电器被短接，电阻≈0）和断路（电路断开，电流=0）。结合电流表、电压表、灯泡亮暗快速判断。

判断口诀表（串联电路，L 为待测灯，$R$ 为另一用电器）

故障电流表 A电压表 V（测 L）灯泡 L
L 断路无示数（=0）有示数，≈电源电压不亮
L 短路有示数（变大）无示数（=0）不亮
R 断路无示数无示数不亮
R 短路有示数（变大）有示数（≈电源）亮
📌 核心技巧：电压表"有示数且接近电源"= 它两端以外的部分断路。 因为电压表内阻极大，串联在断路处时几乎分走全部电压，所以测到≈电源电压，说明故障点就在电压表所测元件之外（即与之串联的元件断路）。
⚠️ 易混点：
  • 电压表有示数且≈电源 → 通常不是被测元件断路（若被测元件断路，电压表无电流回路，应为 0）。
  • 电流表有示数 → 电路未断，故障必为短路。
  • 两表都无示数 → 电路断路，且断路点在电压表所测范围之内。
例：如图串联电路，闭合开关后两灯都不亮，电流表无示数，电压表有示数且接近电源电压。故障是？
解：电流表为 0 → 电路断路；电压表有示数≈电源 → 断路点在电压表所测元件之外。
答：若电压表测 L₁，则故障为 L₂ 断路（L₂ 断开使电压表串入电路测到电源电压）。

3电功率综合计算

电功率是计算题压轴的核心，常考：额定/实际功率转换、挡位问题、取值范围与最值。

① 额定功率与实际功率

$$P_{\text{额}} = U_{\text{额}} I_{\text{额}} = \dfrac{U_{\text{额}}^2}{R},\qquad \dfrac{P_{\text{实}}}{P_{\text{额}}} = \left(\dfrac{U_{\text{实}}}{U_{\text{额}}}\right)^2$$
📌 电阻不变（纯电阻、温度忽略）时，功率与电压平方成正比。这是"同一用电器在不同电压下"转换的关键。

② 挡位问题（家庭电路 U=220V）

两电阻 $R_1$、$R_2$ 组合，总功率 $P = \dfrac{U^2}{R_{\text{总}}}$。总电阻越小，功率越大（高档）。

连接方式总电阻总功率挡位
只接 $R_1$$R_1$$U^2/R_1$单挡
$R_1$ 与 $R_2$ 串联$R_1+R_2$（最大）$U^2/(R_1+R_2)$（最小）低挡
$R_1$ 与 $R_2$ 并联$R_1R_2/(R_1+R_2)$（最小）最大高挡

③ 取值范围与最值（压轴必考）

电压表有量程、电流表有量程、用电器有额定电流，滑片移动时各量有范围。步骤：

  1. 找最值约束：电压表不超量程、电流不超用电器额定电流 / 电流表量程。
  2. 由约束列不等式求滑变 $R_{\text{滑}}$ 的取值范围。
  3. 电路功率 $P_{\text{总}} = \dfrac{U^2}{R_0+R_{\text{滑}}}$，求最大 / 最小功率。
例（压轴）：电源电压 6 V，定值电阻 $R_0=10\ \Omega$ 与滑变 $R_{\text{滑}}$（0~20 Ω）串联，电压表测 $R_0$（量程 0~3 V）。求：(1) $R_{\text{滑}}$ 允许的取值范围；(2) 电路最大总功率。
解：(1) 电压表测 $R_0$：$U_0 = I R_0 \le 3\ \text{V} \Rightarrow I \le 0.3\ \text{A}$。
$I = \dfrac{6}{10+R_{\text{滑}}} \le 0.3 \Rightarrow 10+R_{\text{滑}} \ge 20 \Rightarrow R_{\text{滑}} \ge 10\ \Omega$。又 $R_{\text{滑}}\le 20\ \Omega$，故 $10\ \Omega \le R_{\text{滑}} \le 20\ \Omega$。
(2) 总功率 $P = \dfrac{6^2}{10+R_{\text{滑}}}$，当 $R_{\text{滑}}$ 最小（10 Ω）时最大：
$P_{\max} = \dfrac{36}{20} = \mathbf{1.8\ W}$。

4电热综合（结合 I-U / U-I 图象）

近年压轴题大量采用图象法：给出两电阻的 $I-U$ 图象，求电阻、实际功率、电功。关键是从图象上取点求电阻。

读图三步

  1. 在图象上找易读坐标点（如整数坐标）。
  2. 由 $R = \dfrac{U}{I}$ 算出定值电阻（直线过原点 → 线性电阻）。
  3. 结合串并联规律求总电流 / 总电压，再算 $P=UI$、$W=UIt$。
例（压轴·图象）：两定值电阻 $R_1$、$R_2$ 的 $I-U$ 图象均为过原点的直线，且 $R_1$ 更陡（斜率更大）。将两者并联接在 6 V 电源上，求：(1) $R_1$、$R_2$ 阻值（由图得 $R_1$ 上点 (2V,0.4A)，$R_2$ 上点 (4V,0.2A)）；(2) 干路电流；(3) 电路总功率。
解：(1) $R_1 = \dfrac{2}{0.4} = 5\ \Omega$；$R_2 = \dfrac{4}{0.2} = 20\ \Omega$。
(2) 并联各支路电压均为 6 V：$I_1 = 6/5 = 1.2\ \text{A}$，$I_2 = 6/20 = 0.3\ \text{A}$；干路 $I = 1.5\ \text{A}$。
(3) 总功率 $P = UI = 6\times1.5 = \mathbf{9\ W}$（或 $P = \dfrac{6^2}{5}+\dfrac{6^2}{20} = 7.2+1.8 = 9\ \text{W}$）。

焦耳定律（纯电阻电路）

$$Q = I^2 R t = \dfrac{U^2}{R}t = Pt \quad (\text{纯电阻，电能全转化为热})$$
⚠️ 非纯电阻（如电动机）：$W = UIt$ 是总电能，$Q = I^2Rt$ 只是发热部分，$W > Q$，不能用 $Q=U^2t/R$。初中压轴通常考纯电阻，但若出现"电动机""电风扇"要警惕。

真题一：2025·上海静安·二模

题目：在图所示的电路中，电源电压为 9 V，电阻 $R_1$ 的阻值为 10 Ω，电流表的表盘如图所示。

（a、b 为接入滑动变阻器 $R_2$ 的两点）

第(1)问闭合开关 S，求电流表的示数 I
解：电路中只有 $R_1$ 接入，电流表测通过 $R_1$ 的电流。
$I = \dfrac{U}{R_1} = \dfrac{9\ \text{V}}{10\ \Omega} = \mathbf{0.9\ A}$。
第(2)问接入滑动变阻器 $R_2$，a、b 两点间分别用两种方式连接，测得电流表示数最大、最小值部分数据如下表，求：① $I_{2\max}$；② $R_{2\max}$
电流表示数最小值电流表示数最大值
方式一0.3 A—
方式二—2.9 A
判断连接方式：
电源电压固定为 9 V。若 $R_2$ 与 $R_1$ 串联，总电阻变大，电流会小于原来的 0.9 A；若 并联，总电阻变小，干路电流会大于 0.9 A。
表中方式一最小电流为 0.3 A（< 0.9 A）→ 方式一为 串联；方式二最大电流为 2.9 A（> 0.9 A）→ 方式二为 并联。
① 求 $I_{2\max}$（并联方式）：
并联时干路最大电流 $I_{\max} = 2.9\ \text{A}$，$R_1$ 支路电流恒为 $I_1 = 0.9\ \text{A}$。
由并联分流：$I_{2\max} = I_{\max} - I_1 = 2.9\ \text{A} - 0.9\ \text{A} = \mathbf{2\ A}$。
② 求 $R_{2\max}$（串联方式）：
串联时电流最小时，滑动变阻器接入电阻最大，即 $I_{\min} = 0.3\ \text{A}$。
$R_{\text{总}} = \dfrac{U}{I_{\min}} = \dfrac{9\ \text{V}}{0.3\ \text{A}} = 30\ \Omega$。
$R_{2\max} = R_{\text{总}} - R_1 = 30\ \Omega - 10\ \Omega = \mathbf{20\ \Omega}$。
📌 这道题的核心突破口：通过"电流与 0.9 A 比较"判断串、并联方式。串联让电流变小，并联让干路电流变大。判断出连接方式后，分别用串/并联规律和欧姆定律即可求解。

第(1)问① 本实验的原理是______；② 调整前小灯泡无法正常发光的原因是什么？
① 测电阻的原理：$R = \dfrac{U}{I}$（欧姆定律变形）。

$U = U_L + U_{\text{滑}} = 4.5\ \text{V} + 1.5\ \text{V} = \mathbf{6\ V}$。
第(1)问④ 小灯泡正常发光时的电阻 $R_x$（精确到 0.1 Ω）
正常发光时 $U_L = 3.8\ \text{V}$。由表格数据，当滑动变阻器电压 $U_{\text{滑}} = 6 - 3.8 = 2.2\ \text{V}$ 时对应第 3 组，电流 $I = 0.30\ \text{A}$。
$R_x = \dfrac{U_L}{I} = \dfrac{3.8\ \text{V}}{0.30\ \text{A}} = \mathbf{12.7\ \Omega}$。
第(2)问利用现有器材，能否"探究通过导体的电流与电压的关系"？说明理由。
答：不能。
理由：探究电流与电压的关系时，必须控制导体的电阻不变；而小灯泡的电阻会随温度升高而明显增大，无法保证电阻恒定，因此不能用小灯泡完成该实验。
📌 这道题的易错点：① 注意"电压表示数随电流增大而减小"说明电压表测的是滑动变阻器；② 3.8 V 额定电压要用"$U - U_{\text{滑}}$"去找对应数据，而不是看电压表读数；③ 控制变量法要求电阻不变，灯泡电阻随温度变化，不能替代定值电阻。

真题四：2014·上海·中考真题（判断变阻器规格）

题目：在图（a）所示的电路中，滑动变阻器 $R_2$ 是规格为"20Ω 2A"和"5Ω 3A"中的一个。闭合电键 S，当变阻器连入电路的电阻恰为其最大阻值的一半时，电流表的示数为 0.3 A。此时：

第①问若电阻 $R_1 = 20\ \Omega$，求 $R_1$ 两端的电压 $U_1$。

第②问若电路中正确连入两个电压表，示数分别如图（b）、（c）所示，判断 $R_2$ 的规格，并求 $R_1$ 消耗的电功率 $P_1$。
第一步：读出两表所有可能值。
图（b）指针：0~3 V 量程读 0.9 V，0~15 V 量程读 4.5 V。
图（c）指针：0~3 V 量程读 1.5 V，0~15 V 量程读 7.5 V。
第二步：假设电压表接在 $R_2$ 两端，看是否与可能值吻合。
若 $R_2$ 规格为"20Ω 2A"，接入一半为 $10\ \Omega$，则 $U_2 = I R_2' = 0.3\ \text{A} \times 10\ \Omega = 3\ \text{V}$。
若 $R_2$ 规格为"5Ω 3A"，接入一半为 $2.5\ \Omega$，则 $U_2 = 0.3\ \text{A} \times 2.5\ \Omega = 0.75\ \text{V}$。
两表示数中没有 3 V 或 0.75 V，因此电压表不可能都接在 $R_2$ 两端。
第三步：只能是“一个测 $R_1$，一个测电源”。
串联电路：$U = U_1 + U_2$，所以两表示数之差应等于 $U_2$（3 V 或 0.75 V）。
四种组合中：$4.5 - 1.5 = 3\ \text{V}$，$7.5 - 4.5 = 3\ \text{V}$，其它差不等于 3 V 也不等于 0.75 V。
故 $U_2 = 3\ \text{V}$，对应 $R_2$ 规格为 "20Ω 2A"。
第四步：求 $R_1$ 功率。
情形 A：$U = 4.5\ \text{V}$，$U_1 = 1.5\ \text{V}$，则 $P_1 = U_1 I = 1.5\ \text{V} \times 0.3\ \text{A} = \mathbf{0.45\ W}$。
情形 B：$U = 7.5\ \text{V}$，$U_1 = 4.5\ \text{V}$，则 $P_1 = 4.5\ \text{V} \times 0.3\ \text{A} = \mathbf{1.35\ W}$。
答：$R_2$ 规格为"20Ω 2A"，$P_1$ 为 0.45 W 或 1.35 W。
📌 这道题的核心突破口：① 电压表有 0~3 V 和 0~15 V 两种读数可能，必须列出所有组合；② 先假设电压表测 $R_2$，用两种规格算出 $U_2$，与可能值对比排除；③ 利用串联电压关系 $U = U_1 + U_2$ 把"差值"与 $U_2$ 对应；④ 最后不要忘记多解讨论。

5⁺滑动变阻器"型号"考点总结

真题中常给出"甲标 10Ω 3A、乙标 30Ω 2A"之类字样，要求判断某次实验用了哪一个。先把铭牌读懂：

① 铭牌两个数的含义

$$\text{``}R_{\max}\ I_{\max}\text{''}\quad\text{如 ``20Ω 2A'' ⇒ 最大阻值 20Ω，允许通过的最大电流 2A}$$
参数物理意义解题用途
$R_{\max}$（如 10Ω、30Ω）滑片移到一端时的最大阻值决定可调范围；闭合开关（滑变最大）时电路电流最小
$I_{\max}$（如 3A、2A）变阻器允许通过的最大电流电路电流不能超过它，否则烧坏；是选器材的约束

② 题目中"问型号"的四种考法

考法 1：由实测数据反推用了哪个变阻器
用 $R_{\text{滑}} = \dfrac{U_{\text{滑}}}{I}$ 算出某一时刻接入阻值，若它 大于甲的最大阻值，则甲装不下 → 必用乙。
（奉贤一模：小华第 1 次 $R_{\text{滑1}}=18.75\ \Omega>10\ \Omega$ ⇒ 用乙"30Ω 2A"）
考法 2：判断"闭合开关时滑变应在最大阻值处"
实验步骤正确 → 闭合开关前滑片置于阻值最大端（保护电路）。此时 $R_{\text{滑}}=R_{\max}$，对应最小电流。
（奉贤一模：小红用甲，闭合时 $R_{\text{滑}}=10\ \Omega$，与小华第 2 组对应）
考法 3：用 $I_{\max}$ 校验 / 选择器材
算出电路最大电流，必须 $\le I_{\max}$；否则该变阻器不可用，需换规格。
（如测得干路电流 2.9 A，则"2A"的乙不能用，"3A"的甲才行）
考法 4：结合"电源电压为某整数倍"锁定未知量
奉贤题额外给"电源电压为 1.5 V 整数倍"，把由滑变反推的电压凑成最近的整数倍即可唯一确定。

③ 通用判断流程（压轴套路）

  1. 从任一组数据算 $R_{\text{滑}} = U_{\text{滑}}/I$，与各个变阻器的 $R_{\max}$ 比较，排除装不下的；
  2. 利用"步骤正确 ⇒ 闭合时滑变最大"，把该最大阻值代入求电源电压 / 其他量；
  3. 用 $I_{\max}$ 验证电流不超过限值；
  4. 若仍不唯一，用题给的额外条件（整数倍、表盘读数范围）锁定。
⚠️ 易错点：
  • "$R_{\max}$"是最大阻值不是当前阻值；说"用了 20Ω 变阻器"是指它最大能到 20Ω。
  • 反推时用的是某一状态的 $R_{\text{滑}}$，该值可以小于 $R_{\max}$；只有大于 $R_{\max}$ 才能排除。
  • $I_{\max}$ 是最大允许电流，不是额定电流，也不是正常工作电流。
  • 两变阻器"其他器材相同"，意味着待测电阻、电源、表都一样，差异只在滑变规格。

🎯 压轴题通用四步：
  1. 画等效电路：去掉电表（A 视为导线、V 视为断路），看清串并联。
  2. 标已知：电源、定值电阻、量程、额定值。
  3. 列方程：欧姆定律 + 功率公式 + 串并联规律。
  4. 验范围：检查是否超电压表 / 电流表 / 额定电流。
📝 阅卷高频扣分点：
  • 动态电路把"串反并同"用反（先判断串联还是并联！）。
  • 故障题中"电压表≈电源"误判为被测元件断路。
  • 挡位问题低/高挡对应串/并联写反。
  • 实际功率忘记用电压平方比，直接按比例。
  • 非纯电阻电路误用 $Q=U^2t/R$。
  • 伏安法测灯泡电阻时，把电压表测"滑变"的读数当成灯泡电压。
  • 用灯泡代替定值电阻探究 $I-U$ 关系，忽略温度对电阻的影响。
  • 忘记用"电源电压为 1.5 V 整数倍"这一条件锁定电源电压。
  • 根据一次 $R_\text{滑}$ 数据就判断变阻器规格，没有验证最大阻值。
