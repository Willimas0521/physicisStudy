1电路故障与本质

电路故障指电路连接好后，因为某个元件（或导线）出现问题，导致用电器 不能正常工作 或 仪表读数异常 的现象。

故障的本质：电路中某处 电阻 发生了异常变化——要么变得极大（相当于断开），要么变得极小（相当于导线直接连通）。电流路径因此被破坏或改变。
中考只考两种：断路 与 短路。不管题目多复杂，故障类型都逃不出这两种，因此用"穷举法"列出所有可能再排除，是最稳的解法（详见第 3 节）。
正常通路：有电流，用电器工作 断路（开路）：电流为零 短路：电流绕过某用电器
三种基本状态：通路有电流、断路无电流、短路电流绕过用电器

2两种基本故障

① 断路（开路）

电路中某处断开，电流无法形成闭合回路，电路中没有电流。

常见原因：灯泡灯丝烧断、开关接触不良、导线断开或接头松动、电流表/电压表内部断开、用电器损坏。

② 短路

电流不经过用电器，直接由导线连通形成回路。分两种情况：

  • 电源短路：导线直接连接电源两极，电流极大，会 烧毁电源，绝对要避免！
  • 用电器短路（局部短路）：某用电器被导线直接连通，电流绕过它，该用电器 不工作但不损坏 其他部分。
危险提醒：电源短路时电路中电阻极小，根据 $I = \dfrac{U}{R}$，电流会变得非常大，可能烧坏电源和导线，实验中严禁发生！
$$I = \frac{U}{R}\quad\text{（}R\text{ 极小 }\Rightarrow I\text{ 极大）}$$

3根本思想：穷举法

中考电路故障，本质就 两种：断路 和 短路。题目通常给出两个元件（如电阻 $R$ 和灯泡 $L$），问"到底是哪个出错了"。

统一方法 —— 穷举法：把所有可能的故障 一项项列出来，再根据题给现象 逐一排除，最后剩下的就是答案。
例如两个元件 $R$、$L$，先穷举出全部 4 项：
①②③④
$R$ 短路 $R$ 断路 $L$ 短路 $L$ 断路

拿到题目后，先看灯泡亮不亮、电流表/电压表有无示数，对照这 4 项，把不符合的划掉，剩下的就是故障。下面两条规则是"排除"时最有力的工具。

规则一：用电流表判断

若 电流表没有示数（示数为 0），说明 电流表所在的串联电路出现了断路。
（因为串联只有一条路，一处断开整条路无电流，电流表自然没读数。）

规则二：用电压表判断

若 电压表没有示数（示数为 0），说明 电压表所在的并联电路出现了短路。
（被短路的元件两端电压被导线拉成 0，并联在它两端的电压表也测到 0。）
两条规则的记忆口訣：
• 电流表无示数 → 它那条串联路断路；
• 电压表无示数 → 它并联的那段短路。
反过来，电流表有示数说明 整条串联路是通的（没有断路）；电压表有示数（接近电源电压）说明 它并联的那段是断的（断路处分得几乎全部电压）。

规则三（辅助）：导线（或灯泡）并联法

用一根导线（或一个完好的灯泡）并联在怀疑断路的元件两端：

  • 若接上后其他用电器工作 → 该元件 断路；
  • 若仍不工作 → 故障在别处。

4串联电路：四项穷举

串联电路中，电流只有 一条路径，一处断路则 全电路无电流。设两元件 $R$（电阻）、$L$（灯泡）串联，电流表测总电流，电压表并联在 $R$ 两端。按穷举法，先列出全部 4 项故障：

穷举项现象（灯 $L$）电流表电压表（测 $R$）判定
① $R$ 断路不亮无示数（串联路断）示数≈电源电压电压表串入测总压
② $R$ 短路更亮示数变大无示数（并联段短）电流绕过 $R$
③ $L$ 断路不亮无示数（串联路断）示数 = 0（被断点隔开）电压表无回路
④ $L$ 短路不亮示数变大示数≈电源电压全压加在 $R$ 上
用两条规则做排除：
• 电流表无示数 → 串联路断 → 只可能是 ① $R$ 断路 或 ③ $L$ 断路（先划掉 ② ④）；再用电压表有无示数区分：$R$ 断电压表有示数、③ $L$ 断电压表无示数。
• 电流表有示数 → 串联路通 → 只可能是 ② $R$ 短路 或 ④ $L$ 短路（先划掉 ① ③）；再看电压表：② 无示数、$L$ 短则有示数。
一句话：两灯都不亮 + 电流无示数 = 某处断路；一灯亮一灯不亮 + 电流有示数 = 不亮的被短路。
串联电路：电压表并联在 L₁ 两端，是判断 L₁ 是否断路的关键仪表

5并联电路：只考断路

并联电路中各支路 互不影响。一条支路断路，其他支路仍正常工作；但 干路 断路则全电路停止工作。

为什么并联一般只考"断路"？因为并联中若某一条支路发生 短路，电流会直接连通电源两极，变成 电源短路——这是会烧毁电源的危险状态，实际电路和考题里都不会让它发生。所以并联故障题中，几乎只讨论 哪条支路断路。
故障情况本支路其他支路干路电流
某支路断路该支路用电器不工作正常工作变小（少一条支路）
干路断路全部不工作全部不工作为 0
某支路短路电源短路（危险，一般不考）
并联穷举与判断：
• 一支路不亮、另一支路仍亮 → 不亮的支路 断路（互不影响，正是并联特征）；
• 全部突然不亮 + 干路电流表无示数 → 干路断路；
• 全部不亮且电源发烫 → 才可能涉及 电源短路（极少见）。
并联电路：各支路独立，支路断路只影响本支路；干路断路影响全部

6典型习题

1．（2025·江苏南京·一模）如图所示，闭合开关 S 后，发现灯 $L_1$、$L_2$ 均不发光，电流表无示数。用电压表测得 $L_1$ 两端电压接近电源电压，则故障可能是（　　）

  • A．$L_1$ 短路
  • B．$L_2$ 短路
  • C．$L_1$ 断路
  • D．$L_2$ 断路
【答案】C 【难度】0.60
展开详解

穷举四项错误：① $L_1$ 短路　② $L_2$ 短路　③ $L_1$ 断路　④ $L_2$ 断路。
用规则排除：电流表 无示数 → 电流表所在的串联电路 断路，先划掉 ①②（短路时电流有示数）；剩下 ③④。
再看电压表并联在 $L_1$ 两端 示数≈电源电压 → $L_1$ 这一段是断的（断路处分得几乎全部电压），划掉 ④（$L_2$ 断时电压表被断开隔成无示数）。唯一剩下 ③ $L_1$ 断路。

故选 C。

2．（2025·广东深圳·二模）在探究串联电路特点的实验中，闭合开关后发现 $L_1$ 发光、$L_2$ 不发光，电流表有示数。下列关于故障的判断正确的是（　　）

  • A．电路一定发生了断路
  • B．$L_2$ 断路
  • C．$L_2$ 被短路
  • D．$L_1$ 被短路
【答案】C 【难度】0.55
展开详解

穷举四项错误：① $L_1$ 短路　② $L_2$ 短路　③ $L_1$ 断路　④ $L_2$ 断路。
用规则排除：电流表 有示数 → 串联电路是通的，没有断路，划掉 ③④（断路时电流表无示数）；剩下 ①②。
$L_1$ 亮、$L_2$ 不亮，说明电流绕过了 $L_2$ 而经过 $L_1$ → $L_2$ 被短路（即 ②）。若 ① $L_1$ 短路则应是 $L_1$ 不亮、$L_2$ 更亮，与题意相反，划掉。

故选 C。

3．（2024·浙江杭州·中考）家庭电路中，某盏电灯突然熄灭，但其余电灯仍正常发光，这说明该电灯所在支路（　　）

  • A．发生断路
  • B．发生短路
  • C．总开关跳闸
  • D．电源电压降低
【答案】A 【难度】0.50
展开详解

家庭电路中各用电器是 并联 的，各支路互不影响（并联一般只考断路）。一盏灯熄灭而其余正常，说明该灯所在支路 断路（如灯丝烧断、开关接触不良）。若是短路，会造成干路电流过大使保险丝熔断或跳闸，所有用电器都会断电（排除 B）；总开关跳闸会使全屋断电（排除 C）。

故选 A。

4．（模拟·并联穷举）如图所示，两灯 $L_1$、$L_2$ 并联，闭合开关后 $L_1$ 不亮、$L_2$ 仍正常发光，电流表 $A_1$（干路）有示数。下列故障判断正确的是（　　）

  • A．$L_1$ 短路
  • B．$L_2$ 短路
  • C．$L_1$ 断路
  • D．干路断路
【答案】C 【难度】0.45
展开详解

穷举并联可能性：并联不考短路（短路=电源短路，不会让它发生），所以只穷举断路：$L_1$ 支路断、 $L_2$ 支路断、干路断。
$L_2$ 仍亮 → 不是干路断（否则全不亮），也不是 $L_2$ 支路断；$L_1$ 不亮而 $L_2$ 亮，正是"互不影响"的典型表现 → $L_1$ 支路断路。
若选 A（$L_1$ 短路）则会造成电源短路，两灯都不亮且电源危险，与题意不符。

故选 C。
