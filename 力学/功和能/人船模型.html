📐 模型定义

如图所示为一条宽为 d 的大河，小明驾着小船从 A 点出发，欲将一批货物运送到对岸。已知河水流速为 v水，小船在静水中的航速为 v船。

船的实际运动是水流的运动和船相对静水的运动的合运动。

三个速度：

  • v船：船在静水中的速度
  • v水：水流速度
  • v：船的实际速度（合速度）

💡 要点点拨

  1. 怎么求解小船渡河过程所用的时间？小船如何渡河时间最短？最短时间为多少？此时渡河位移为多大？
  2. 小船如何渡河才能使渡河位移最小？最小位移为多大？
  3. 小船渡河时间的长短与水流速度是否有关？

🛠 解题方法

（1）渡河时间问题

由于水流速度始终沿河岸方向，不能提供指向河岸的分速度，因此过河时间由河的宽度除以垂直于河岸方向的速度得到。

若要渡河时间最短，只要使船头垂直于河岸航行即可。

tmin = d / v船

此时小船还会被河水冲向下游，下游漂移距离：

x = v水 · tmin = v水d / v船

实际渡河位移大小与方向：

s = √(d² + x²) = d·√[1 + (v水/v船)²]；  tanθ = v水/v船

（2）最小位移渡河

情况一：v水 < v船

最短位移为河宽 d，此时合速度垂直河岸，小船可到达正对岸。

船头与上游河岸夹角 θ 满足：

v船cosθ = v水

渡河所用时间：

t = d / (v船sinθ) = d / √(v船² − v水²)

情况二：v水 > v船

以 v水 矢量的末端为圆心，以 v船 的大小为半径作圆，当合速度方向与圆相切时，合速度方向与河岸的夹角最大（设为 α），此时航程最短，小船不能到达正对岸。

由几何关系：

sinα = v船/v水， cosθ′ = v船/v水

最短位移：

smin = d / sinα = d·v水/v船

📝 规律总结

  • 渡河时间只与垂直河岸的分速度有关；船头垂直河岸时时间最短，且与 v水 无关。
  • 最短位移取决于 v船 与 v水 的大小关系：v船 > v水 时可垂直到达对岸，最小位移为 d；v船 < v水 时最短航程为 d·v水/v船。
  • 处理小船渡河问题的核心是运动的合成与分解：将船速分解为沿河岸和垂直河岸两个分量。
