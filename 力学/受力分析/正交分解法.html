平衡问题 · 考点06

正交分解法

把任意方向上的力分解到两个互相垂直的轴上，列两个代数方程——解平衡题的标准流程。

📘 📐 分解式
$$F_x = F\cos\theta,\quad F_y = F\sin\theta$$
θ 是力与 x 轴的夹角。
📘 🎯 平衡方程
$$\Sigma F_x = 0,\quad \Sigma F_y = 0$$
两方向合力均为零，可解两个未知量。
📘 🧭 选轴技巧
沿运动趋势方向+垂直它
斜面问题通常沿斜面与垂直斜面建系，可避免分解支持力。
💡 例题
沿斜面与垂直斜面正交分解重力：$mg\sin 37° = 12\ \text{N}$，$mg\cos 37° = 16\ \text{N}$
垂直斜面方向：$N = mg\cos 37° = 16\ \text{N}$
沿斜面方向：$f = mg\sin 37° = 12\ \text{N}$
🎮 闯关挑战
1. 物体在斜面上静止，下列四组力中哪一组能保证物体平衡（θ 为斜面倾角）？
AN = mg，f = mgsinθ
BN = mgcosθ，f = mgsinθ
CN = mgsinθ，f = mgcosθ
DN = mg，f = 0
📝 解析：正交分解重力：垂直斜面方向 $N = mg\cos\theta$，沿斜面方向 $f = mg\sin\theta$。
🎮 闯关挑战
2. 质量 m 的物体静止在倾角 θ 的斜面上，现用一沿斜面向上的力 F 推它仍静止，则此时物体受摩擦力（斜面粗糙，mgsinθ > F）为？
Amgsinθ，沿斜面向上
Bmgsinθ - F，沿斜面向上
CF - mgsinθ，沿斜面向上
D0
📝 解析：物体有下滑趋势，摩擦力沿斜面向上：$f + F = mg\sin\theta$，得 $f = mg\sin\theta - F$，方向沿斜面向上。
