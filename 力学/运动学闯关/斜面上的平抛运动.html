斜面上的平抛运动

平抛与斜面结合的高考高频题型：关键看题目给的是速度条件还是位移条件，再决定分解谁。

📘 核心思想
速度条件 → 分解速度；位移条件 → 分解位移
无论哪种，都先把平抛运动拆成水平匀速 $x=v_0t$ 和竖直自由落体 $y=\frac12gt^2$，再利用斜面倾角建立几何关系。
一、若已知平抛运动的速度

解题方法：速度的合成与分解。

1️⃣ 垂直打到斜面上
$v_x = v_0,\quad v_y = gt$
合速度大小 $v = \sqrt{v_0^2+(gt)^2}$；方向：$\tan\theta = \dfrac{v_x}{v_y} = \dfrac{v_0}{gt}$
速度垂直斜面，因此合速度与竖直方向夹角为斜面倾角 θ。
2️⃣ 无碰撞进入斜面轨道
$v_x = v_0,\quad v_y = gt$
合速度大小 $v = \sqrt{v_0^2+(gt)^2}$；方向：$\tan\alpha = \dfrac{v_y}{v_x} = \dfrac{gt}{v_0}$
速度方向沿斜面，因此合速度与水平方向夹角等于斜面倾角 α。
二、若已知平抛运动的位移

解题方法：位移的合成与分解。

3️⃣ 从斜面抛出又落回斜面
$x = v_0t,\quad y = \dfrac12gt^2$
合位移大小 $s = \sqrt{x^2+y^2}$；方向：$\tan\theta = \dfrac{y}{x} = \dfrac{gt}{2v_0}$
落点仍在斜面上，所以合位移方向沿斜面向下，与水平方向夹角为 θ。
4️⃣ 对着斜面水平抛出，落在斜面上位移最小
$x = v_0t,\quad y = \dfrac12gt^2$
合位移大小 $s = \sqrt{x^2+y^2}$；方向：$\tan\theta = \dfrac{x}{y} = \dfrac{2v_0}{gt}$
位移方向垂直斜面，因此合位移与竖直方向夹角为 θ。注意此时 $\tan\theta$ 是水平位移与竖直位移之比。
🎮 闯关挑战
小球从斜面顶端水平抛出后落回同一斜面，斜面倾角为 θ，则 tanθ 等于？
A$\dfrac{gt}{v_0}$
B$\dfrac{gt}{2v_0}$
C$\dfrac{2v_0}{gt}$
D$\dfrac{v_0}{gt}$
📝 解析：落回斜面时，位移方向沿斜面，$\tan\theta = \dfrac{y}{x} = \dfrac{\frac12gt^2}{v_0t} = \dfrac{gt}{2v_0}$，故选 B。
🔑 本关记忆要点：斜面上的平抛 — 给速度条件画速度三角形，给位移条件画位移三角形；两个直角边始终是 $v_0$（或 $v_0t$）与 $gt$（或 $\frac12gt^2$），斜面倾角是联系合量与分量的桥梁。
