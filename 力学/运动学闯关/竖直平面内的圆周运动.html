竖直平面内的圆周运动

竖直平面内的圆周运动是圆周运动与牛顿定律、机械能守恒的综合考点。核心是最高点临界速度、最低点支持力，以及“绳”和“杆”两种约束模型的区别。

一、一般圆周运动的动力学分析

做圆周运动的物体，所受合外力与速度成一般夹角时，可将合外力沿速度方向和垂直速度方向分解，分别提供切向加速度和法向加速度。

📘 动力学方程
$F_\tau=ma_\tau,\quad F_n=ma_n$
$a_\tau=\dfrac{\mathrm{d}v}{\mathrm{d}t}\ \text{（改变速度大小）},\quad a_n=\dfrac{v^2}{r}\ \text{（改变速度方向）}$
对一般曲线运动，取某点附近一小段曲线作曲率圆，曲率半径记为 $\rho$，则 $a_n=\dfrac{v^2}{\rho}$。
二、两类模型
（一）汽车过拱桥

汽车以一定速度通过拱桥（凸形桥最高点）或凹形路面（最低点）时，竖直方向合力提供向心力。

📘 拱桥临界结论
$G-N=m\dfrac{v^2}{R},\quad N=G-m\dfrac{v^2}{R}$（凸形桥最高点）
$N-G=m\dfrac{v^2}{R},\quad N=G+m\dfrac{v^2}{R}$（凹形路面最低点）
凸形桥最高点速度越大，$N$ 越小；当 $v=\sqrt{gR}$ 时 $N=0$，汽车将离开桥面做平抛运动。凹形路面最低点速度越大，$N$ 越大，处于超重状态。
（二）竖直面内圆周运动的两类模型

按最高点是否受“支撑”分为绳（环）约束模型与杆（管）约束模型，临界条件和最高点弹力随速度变化关系不同。

比较项轻绳模型（无支撑）轻杆模型（有支撑）
常见类型绳、圆轨道内侧杆、光滑管道
最高点临界速度$v_{临}=\sqrt{gR}$$v_{临}=0$
最低点最小速度$v_{低}\ge\sqrt{5gR}$$v_{低}\ge\sqrt{4gR}$
最高点弹力只能向下（拉力/压力），$F_N=m\dfrac{v^2}{R}-mg$可为向上支持力或向下压力，随 $v$ 变化
不脱离条件$v_{低}\ge\sqrt{5gR}$只要速度方向不变就不会脱离
📘 完整圆周运动临界分析（光滑圆轨道内侧）
设圆轨道半径为 $R$，最高点为 A，最低点为 C，与圆心等高的位置为 B、D。
$v_A=\sqrt{gR}$（最高点恰好由重力提供向心力）
$\dfrac12mv_C^2=\dfrac12mv_A^2+2mgR\Rightarrow v_C=\sqrt{5gR}$
$v_C=\sqrt{2gR}$（恰能到达与 O 等高的 D 点）
条件运动结果最高点 A 的受力
$v_C>\sqrt{5gR}$能通过最高点 A，继续完整圆周运动轨道向内支持力 $N_A=m\dfrac{v_A^2}{R}-mg$
$v_C=\sqrt{5gR}$恰能通过最高点 A$N_A=0$，仅重力提供向心力
$\sqrt{2gR}<v_C<\sqrt{5gR}$不能通过最高点，在 DA 段某位置斜抛离开离开瞬间 $N_A=0$，速度越大离开位置越高
$v_C\le\sqrt{2gR}$不能通过最高点，上升至 CD 段某位置速度为零后返回永不脱离轨道
📘 最低点轨道作用力常见结论
从 A 点静止释放到 C 点：$N_C=5mg$
从 D 点（与 O 等高）静止释放到 C 点：$N_C=3mg$
从 A 点以 $v_0$ 释放到 C 点：$N_C=mg+m\dfrac{v_C^2}{R}=5mg+m\dfrac{v_0^2}{R}$
🎮 闯关挑战
关于竖直平面内的圆周运动，下列说法正确的是？
A绳模型最高点最小速度为 0
B杆模型最高点最小速度为 $\sqrt{gR}$
C汽车过凸形桥最高点速度越大越安全
D小球从最高点静止下滑到最低点，轨道支持力为 $5mg$
📝 解析：绳模型最高点必须满足 $mg\le m\dfrac{v^2}{R}$，最小速度为 $\sqrt{gR}$；杆模型最高点最小速度为 0；汽车过凸形桥最高点速度越大，$N$ 越小，越不安全；从最高点静止下滑到最低点，由机械能守恒和牛顿第二定律可得 $N_C=5mg$。故选 D。
🔑 本关记忆要点：竖直平面内圆周运动 — 最高点临界看“有无支撑”，绳/环模型 $v_临=\sqrt{gR}$，杆/管模型 $v_临=0$；最低点支持力可用机械能守恒 + 牛顿第二定律求解。
