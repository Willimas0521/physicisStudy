方法专题 · 电场图像

电场中常见的图像

带电粒子在电场中运动时，常借助 φ-x、E-x 等图像分析场强、电势、电势能等物理量的变化规律。本节先从 φ-x 图像入手，掌握读图与定性分析的方法。

一、φ-x 图像

1. 斜率与场强的关系

根据电场强度与电势差的关系，当 $\Delta x \to 0$ 时：

$$E_x = -\frac{\Delta \varphi}{\Delta x}$$
φ-x 图像切线斜率的绝对值表示该点电场强度在 x 轴方向上的大小；斜率的正负表示场强方向。
  • 图甲：斜率不变 → 沿 x 方向电场强度大小不变；
  • 图乙：斜率随 x 增大而减小 → 沿 x 方向电场强度逐渐减小。

2. 由电势高低判断场强方向

设电场强度方向与 x 轴平行：

  • A 点电势高于 B 点电势，则 A、B 间电场方向沿 x 轴正方向；
  • C 点电势低于 D 点电势，则 C、D 间电场方向沿 x 轴负方向。

3. 电势能变化与电场力做功

在 φ-x 图像中分析移动电荷的电势能变化，可用：

$$W_{AB}=qU_{AB}=-\Delta E_p$$
电场力做正功，电势能减小；电场力做负功，电势能增大。

📝 φ-x 图像总结

  • 斜率意义：|k| = |Ex|，斜率正负表示 x 方向场强方向。
  • 电势高低：直接由图像纵坐标读出；沿电场线方向电势降低。
  • 电势能：用 $W_{AB}=qU_{AB}=-\Delta E_p$ 计算或判断增减。
  • 检验电荷电性：结合电势变化与电势能变化，可反推电荷正负。
