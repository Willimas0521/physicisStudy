改装成电压表（串联分压）

\(R=(n-1)R_g\)

📖 实验原理

图 2-1：表头 G 串联大电阻 R，改装成量程为 U 的电压表
图 2-2：改装电压表接入电路，与标准电压表对比读数
改装目标：让表头在指针满偏（流过 \(I_g\)）时，两端的总电压恰好等于新量程 \(U\)。
根据串联电路电压分配：满偏时 \(U = I_g(R_g + R)\)，解得：
\(R = \dfrac{U}{I_g} - R_g\)
　或令量程扩大倍数 \(n = \dfrac{U}{U_g} = \dfrac{U}{I_g R_g}\)，则
\(R = (n - 1)R_g\)
改装后电压表的总内阻：\(R_V = R_g + R = \dfrac{U}{I_g}\)，非常大（串联分压目的就是让电压表内阻尽量大，减小对电路的并联影响）。
读数规律：改装表表盘仍按表头的 Ig 等分刻度，但每一格代表 \(\dfrac{U}{I_g}\times\) 表头每格电流；例如满偏 \(1\ \text{mA}\) 的表头改成 \(3\ \text{V}\) 表，则每格 \(3\ \text{V}/\)总格数。指针半偏 → 读数 = 量程一半。
⚠ 常见误差方向（改电压表）：改装时按标注 \(R_g\) 串电阻。若表头真实内阻比标注值大，则实际量程比标称大 → 同一被测电压下指针偏角偏小 → 读数偏小；反之偏大。

📏 校准电路

电压表校准：将改装表与标准电压表并联在待测电路两端，使用分压式接法，通过滑动变阻器改变并联部分两端的电压，比较两表示数（改装表与标准电压表）。
校准要点：分压式电路中，滑动变阻器采用"一上两下"接法，使电压能从 0 缓慢调至改装表满偏附近，逐点记录改装表读数与标准表读数，画出校准曲线，修正刻度。

🎯 闯关练习

📜 高考真题

（真题改编）把一个满偏电流 \(I_g = 500\ \mu\text{A}\)、内阻 \(R_g = 200\ \Omega\) 的表头改装成两个量程的电压表（\(3\ \text{V}\) 和 \(15\ \text{V}\)），电路为"表头—R₁—R₂"—端公共负极。求 \(R_1\)、\(R_2\)。

答案：接 3 V 挡时串联 R₁，\(R_1 = \dfrac{U_1}{I_g} - R_g = \dfrac{3}{500\times10^{-6}} - 200 = 5800\ \Omega = 5.8\ \text{k}\Omega\)。
接 15 V 挡时串联 R₁+R₂，\(R_1 + R_2 = \dfrac{15}{500\times10^{-6}} - 200 = 29800\ \Omega = 29.8\ \text{k}\Omega\)，故 \(R_2 = 29.8 - 5.8 = 24.0\ \text{k}\Omega\)。
