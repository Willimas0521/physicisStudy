改装成大量程电流表（并联分流）

\(R=\dfrac{R_g}{n-1}\)

📖 实验原理

图 3-1：表头 G 并联小电阻 R 分流，改装成量程为 I 的电流表
图 3-2：改装电流表接入电路，与标准电流表对比读数
改装目标：让总电流达到新量程 I 时，表头恰好流过 Ig（满偏），其余电流全部从分流电阻 R 流过。
并联电路电压相等：满偏时 Rg 两端电压 = R 两端电压，即 \(I_g R_g = (I - I_g)R\)，解得：
\(R = \dfrac{I_g R_g}{I - I_g}\)
　或 \(n = \dfrac{I}{I_g}\)，则
\(R = \dfrac{R_g}{n - 1}\)
改装后电流表总内阻：\(R_A = R_g \parallel R = \dfrac{I_g R_g}{I}\)，非常小（并联分流目的就是让电流表内阻尽量小，减小对电路的串联影响）。
⚠ 对比记忆：
· 改电压表：串大电阻，内阻变大，\(n\) 倍量程串 \((n-1)R_g\)；
· 改电流表：并小电阻，内阻变小，\(n\) 倍量程并 \(\dfrac{R_g}{n-1}\)。
两者都是"表头电流不变，靠外部电阻分担多余电压/电流"。

📏 校准电路

电流表校准：将改装表与标准电流表串联在电路中，使用限流式接法，通过滑动变阻器改变电路中的电流，比较两表示数（改装表与标准电流表）。
校准要点：限流式电路中，滑动变阻器阻值应适中，确保电流能从 0 附近缓慢调至改装表满偏附近，逐点记录改装表读数与标准表读数，画出校准曲线，修正刻度。

🎯 闯关练习

📜 高考真题

（真题改编）表头 \(I_g = 300\ \mu\text{A}\)、\(R_g = 200\ \Omega\)，改装成 \(3\ \text{mA}\) 的电流表。(1) 求并联电阻 \(R\)；(2) 若被测电流为 \(1.5\ \text{mA}\)，表头指针偏转的角度为满偏的几分之几？

答案：(1) \(n = \dfrac{3}{0.3} = 10\)，\(R = \dfrac{R_g}{n-1} = \dfrac{200}{9} \approx 22.2\ \Omega\)。
(2) 流过表头的电流与被测电流成正比：\(I_{\text{g}} = I_g\cdot\dfrac{I}{I_{\text{m}}} = 300\ \mu\text{A}\times\dfrac{1.5}{3} = 150\ \mu\text{A} = \dfrac{I_g}{2}\)，指针偏半偏（满偏的一半）。
