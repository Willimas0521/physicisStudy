滑动变阻器：限流 vs 分压

电路设计

📖 实验原理

限流式与分压式是滑动变阻器在电路中的两种常见接法。

图 6-1：限流式与分压式接法对比

一、它们的区别

1. 电路连接方式
限流式：滑动变阻器与负载（如电阻、灯泡等）串联，滑片移动时改变串联电阻的阻值，从而调节电路中的电流和负载两端的电压。
分压式：滑动变阻器的一部分与负载并联，另一部分与并联部分串联，通过滑片移动改变并联部分的分压，实现负载两端电压从 0 开始连续调节。

2. 电压调节范围
限流式：电压调节范围有限，最小电压不为 0，且调节范围受滑动变阻器最大阻值限制。
分压式：电压可从 0 开始调节，调节范围更广，尤其适用于需要精确控制电压从低到高的实验。

3. 适用场景（选择原则）
以下三种情况一定要选择分压式：
（1）实验要求电压从 0 开始变化。
（2）用限流式"限不住"的情形下。也就是说，如果滑动变阻器的全部电阻都串联入电路，电流仍然会超过电表的量程，那就必须用分压式。
（3）用限流式"调节范围过小"的情形下。例如，待测电阻约 1000 Ω，若滑动变阻器的总阻值是 20 Ω，那就必然出现"调节范围过小"的情况，这就只能用分压式了。
如果没有特殊要求，且 Rx 与滑动变阻器 R0 阻值接近（Rx ≤ R0）就首选限流式了。

图 6-2：限流式与分压式特点对比

限流式适合简单调节、对电压起始值无要求的场景；分压式适合高精度调节、需从 0 开始调压，或负载阻值远大于滑动变阻器阻值的情况。实际应用中需根据实验要求和电路参数选择合适接法。

限流式：电路简单，能耗小。但在测量范围内电压/电流调节范围相对较小。
分压式：电压/电流可以从 0 开始调节，调节范围大。但电路复杂，能耗大。

三、电学实验器材选择原则

· 安全性：不能超过电表的量程和元件的额定值。
· 精确性：尽量使指针偏转在满刻度的 1/3 到 2/3 以上区域，以减少读数误差。
· 可操作性：在满足实验要求的前提下，滑动变阻器要便于调节。

📜 高考真题

（真题改编）用伏安法测额定电压 2.5 V 小灯泡的伏安特性曲线，实验要求电压从 0 开始逐渐增大。请说明滑动变阻器应采用限流式还是分压式，并说明理由；小灯泡的电阻约 10 Ω，电流表内阻约 0.2 Ω，电压表内阻约 3 kΩ，电流表应内接还是外接？

答案：①变阻器用分压式——伏安特性要求电压从 0 开始连续可调，限流式调不到 0。
②电流表用外接法——小灯泡 Rₓ≈10 Ω 很小，Rₓ ≪ RV(3 kΩ)，外接误差小；且外接时电压表并联灯泡两端，读数即灯泡真实电压。
