电桥法测电阻（惠斯通电桥）

桥路平衡 · 比较法 · 高精度

📖 实验原理

图 11-1：惠斯通电桥（四个桥臂 + 电源对角 + 检流计对角）
电路结构：把四个电阻 R₁、R₂、R₃、Rₓ 依次连成一个四边形：电源接在一条对角线（A—C）上，灵敏电流计 G 接在另一条对角线（B—D）上——这条中间支路就叫"桥"。
平衡条件：调节电阻使 检流计指零，即桥路电流
I_G = 0
，此时 B、D 两点电势相等。两条支路的分压比因此相同：
R₁ / R₂ = R₃ / Rₓ
　⇔　
R₁·Rₓ = R₂·R₃
（对臂乘积相等）
待测电阻：
Rₓ = (R₂ / R₁)·R₃

其中 R₁、R₂ 叫比例臂（提供倍率 R₂/R₁），R₃ 叫比较臂（可调电阻箱），Rₓ 为待测臂。
例：
R₁/R₂ = 100/10
，
R₃ = 23.6 Ω
时平衡，则
Rₓ = 0.1 × 23.6 = 2.36 Ω
。
为什么比伏安法准？电桥法属于比较法（零示法）：只判断桥上"有没有电流"，不读电表的数值，所以结果与电源电压、检流计内阻、电表精度全都无关，没有伏安法那种"内接偏大 / 外接偏小"的方法误差。这是中学阶段精度最高的测电阻方法。
⚠ 注意：平衡条件只由电阻比决定，与电源电压无关——把电源电压加倍，电桥仍然平衡，只是灵敏度变高（但电压过大会烧坏桥臂）。
滑线式电桥（高中常见）：用一根均匀电阻丝代替两个比例臂，触头把电阻丝分成 L₁、L₂ 两段。因电阻与长度成正比：
Rₓ = R·L₂ / L₁

调节触头位置使检流计指零，再用刻度尺量出两段长度即可，无需精密电阻。
交换法（减小系统误差）：把 R 与 Rₓ 互换位置再测一次，取两次结果的几何平均：
Rₓ = √(Rₓ₁·Rₓ₂)
这样可以抵消电阻丝粗细不均、触头零点（端点）偏差带来的系统误差。
灵敏度：电源电压越高、检流计越灵敏、四个桥臂阻值越接近（比例臂取 1∶1 附近），电桥越灵敏；但要注意各桥臂的额定电流，防止烧毁。
⚠ 主要误差来源：① 电阻丝不均匀或长度读数误差；② 触头处的接触电阻（滑线式电桥）；③ 桥臂电阻本身不准；④ 检流计不够灵敏造成"假平衡"。前两项可用交换法显著减小。

🎯 闯关练习

📜 高考真题

（真题改编）用滑线式电桥测未知电阻 \(R_x\)：均匀电阻丝全长 \(100.0\ \text{cm}\)，电阻箱 \(R = 20.0\ \Omega\)。

(1) 第一次平衡时触头距电阻丝左端 \(40.0\ \text{cm}\)（\(R\) 接在左侧），求 \(R_x\)；

(2) 保持触头位置不变，把电源电压提高到原来的 2 倍，检流计指针会怎样？电桥是否仍平衡？

(3) 如何用"交换法"进一步提高测量精度？

答案：(1) 由 \(\dfrac{R}{R_x} = \dfrac{L_1}{L_2}\)，得 \(R_x = R\cdot\dfrac{L_2}{L_1} = 20.0\times\dfrac{60.0}{40.0} = 30.0\ \Omega\)。
(2) 平衡条件只与电阻比有关，与电源电压无关，故电桥仍平衡，检流计指针仍指零（不偏转）；只是电压升高后灵敏度变大。
(3) 将 \(R\) 与 \(R_x\) 互换位置，重新调节触头使检流计指零，得到 \(R_{x2}\)；取两次结果的几何平均 \(R_x = \sqrt{R_{x1}R_{x2}}\)，可消除电阻丝粗细不均和触头零点偏差带来的系统误差。
