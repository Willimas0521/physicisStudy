▶知识框架

单棒切割是电磁感应中最经典、最常考的模型：一根导体棒在磁场中运动，棒两端产生感应电动势，与外电路构成闭合回路。

📌 一条主线（四步分析法）：
  1. ① 动生电动势：$E = BLv$（平动）或 $E=\frac12 B\omega L^2$（转动）；
  2. ② 闭合回路电流：$I=\dfrac{E}{R+r}$，安培力 $F_\text{安}=BIL=\dfrac{B^2L^2v}{R+r}$；
  3. ③ 受力与运动：牛顿第二定律求加速度，分析收尾（匀速）状态；
  4. ④ 电荷与能量：$q=\dfrac{\Delta\Phi}{R+r}$，克服安培力做功等于焦耳热。

💡 本页为自由学习模式，所有小节都能直接查看；每节底部配小测验，仅作自我检测。

1单棒模型分类

高考中"单棒在磁场中运动"可以按"棒本身是否提供电源"与"外电路是电阻还是电容"分成几类。下面把最常见的四类拎出来，先建立整体印象。

1．无外力 + 电阻 + 单棒 + 有初速度

📌 初始条件：轨道水平且光滑，导体棒有初速度 $v_0$，向右为正方向；棒电阻不计，导轨间接有定值电阻 $R$。

运动分析：

  • 棒以 $v_0$ 切割磁感线，产生感应电动势 $E=BLv$；
  • 闭合回路中有感应电流 $I=\dfrac{BLv}{R}$；
  • 棒受到向左的安培力 $F_\text{安}=BIL=\dfrac{B^2L^2v}{R}$；
  • 由牛顿第二定律，$-F_\text{安}=ma$，即棒从 $v_0$ 开始减速。

随着速度减小，安培力减小，加速度也减小——这是加速度减小的减速运动。最终速度趋近于 0，棒静止。

$$v(t):\ v_0 \xrightarrow{\text{加速度减小的减速}} 0$$

能量规律：导体棒的初动能全部转化为电阻 $R$ 上的焦耳热，即

$$Q = \frac12 mv_0^2$$

动量规律：安培力的冲量等于杆的动量变化量，即

$$-\,B\,L\,q = 0 - mv_0 \quad \Rightarrow \quad q = \frac{mv_0}{BL}$$

又因为 $q=\dfrac{\Delta\Phi}{R}=\dfrac{BLx}{R}$，可进一步求出全过程棒的位移 $x=\dfrac{mv_0R}{B^2L^2}$。

2．有外力 + 电阻 + 单棒

📌 外力来源：可以是水平拉力 $F$、竖直重力 $G$、斜面上重力的分力 $mg\sin\theta$ 等。这里以水平恒力 $F$ 为例。

棒从静止出发，初始速度小，安培力小，$F>F_\text{安}$，加速；随着速度增大，安培力 $F_\text{安}=\dfrac{B^2L^2v}{R+r}$ 增大，加速度减小。最终 $F=F_\text{安}$，加速度为零，速度达到最大收尾值 $v_m$。

$$v_m = \frac{F(R+r)}{B^2L^2}$$

如果是竖直下落（只受重力），收尾速度 $v_m=\dfrac{mg(R+r)}{B^2L^2}$；如果是光滑斜面下滑，则 $v_m=\dfrac{mg\sin\theta\,(R+r)}{B^2L^2}$。

3．无外力 + 电源 + 单棒

导轨回路中串入电动势为 $E$ 的电源（方向使棒向右加速）。闭合开关后，电源提供电流，棒在磁场中受安培力向右运动。棒一旦运动，又产生反向感应电动势 $E_\text{感}=BLv$，削弱回路电流。

电流随速度增大而减小，安培力减小，加速度减小。当 $BLv_m = E$ 时，回路电流为零，安培力为零，棒以

$$v_m = \frac{E}{BL}$$

匀速运动。全过程电源输出的电能转化为棒的动能。

4．有外力 + 电容 + 单杆

电容器并联在导轨两端，外力 $F$ 水平向右拉棒。棒运动时切割产生电动势 $E=BLv$，给电容充电，电容器两端电压 $U_C$ 随 $v$ 增大而升高。

若回路电阻可忽略，则 $U_C = BLv$。电容器电荷量 $Q_C = C\,U_C = CBLv$，于是回路电流

$$I = \frac{dQ_C}{dt} = C\,B\,L\,\frac{dv}{dt} = C\,B\,L\,a$$

对棒列牛顿第二定律：

$$F - B\,I\,L = ma \quad \Rightarrow \quad F - B^2L^2C\,a = ma$$

整理得

$$a = \frac{F}{m + B^2L^2C}$$
📌 核心结论：恒外力 + 电容 + 无电阻导轨，棒做匀加速直线运动，加速度 $a=\dfrac{F}{m+B^2L^2C}$。这是与"电阻模型"截然不同的运动形态。

5．两类电容补充模型

模型电路特征运动特征
电容 + 单棒 + 有初速度电容跨接导轨，棒有 $v_0$，无电源无外力棒减速，电容充电；最终电流为零，$U_C=BLv_\text{末}$，棒以 $v_\text{末}$ 匀速（若有电阻则最终停下）
充电/放电式电容 + 电源 + 单棒 + 外力先由电源给电容充电，再接入导轨；或电容与电源、导轨、棒组成回路电容放电提供电流，棒受安培力加速；同时棒切割产生反电动势，最终 $U_C=BLv_\text{末}$ 时电流为零，系统趋于稳定
⚠️ 区分要点：电阻模型最终常是"收尾速度"；无电阻电容模型最终常是"匀加速"或"电流为零的匀速"，列式时要抓住 $I=\dfrac{dQ_C}{dt}=CBL\,a$ 这一关系。

2感应电动势

1．平动切割（动生电动势）

长为 $L$ 的导体棒，以速度 $v$ 垂直切割磁感应强度为 $B$ 的匀强磁场，棒两端产生的感应电动势为

$$E = B\,L\,v$$

适用条件：$B$、$L$、$v$ 三者两两垂直。若速度方向与棒不垂直，取垂直于棒的分速度 $v_\perp$。

📌 等效电源：切割磁感线的导体棒相当于电源，棒内部电流从低电势流向高电势（负极→正极）；电动势方向由右手定则（或楞次定律）判定。

2．转动切割

长为 $L$ 的导体棒绕其一端、以角速度 $\omega$ 在垂直磁场平面内转动，棒上各点线速度不同，平均速度为 $\dfrac{\omega L}{2}$，故

$$E = \frac12\,B\,\omega\,L^2$$

3．有效长度

弯曲导体或斜放导体切割时，$L$ 取导体两端点在垂直速度方向上的投影距离（即"参与切割的有效长度"）。

⚠️ 易错：$E=BLv$ 中的 $L$ 是有效切割长度，不是导体的几何总长。只有垂直切割磁感线的那部分才产生电动势。

3电路与安培力

1．回路电流

棒作电源，电动势 $E=BLv$，全电路总电阻为 $R+r$（$R$ 为外电阻，$r$ 为棒电阻），则感应电流

$$I = \frac{E}{R+r} = \frac{BLv}{R+r}$$

2．安培力（阻力）

通电导体棒在磁场中受安培力，大小为

$$F_\text{安} = B\,I\,L = \frac{B^2L^2v}{R+r}$$

方向由左手定则判定，结果总是阻碍导体棒的相对运动（楞次定律的"阻碍"在力学上的体现）。

📌 记忆：棒被拉动时，安培力与运动方向相反（阻力）；棒自由运动时，安培力使其减速——能量最终变为焦耳热。

4动力学 · 收尾速度

1．牛顿第二定律

棒受外力 $F_\text{牵}$、安培力 $F_\text{安}$、摩擦力 $f$、重力分量等，加速度为

$$a = \frac{F_\text{牵} - F_\text{安} - f - mg\sin\theta}{m}$$

其中 $F_\text{安}=\dfrac{B^2L^2v}{R+r}$，$v$ 越大，安培力越大，加速度越小——这是变加速过程。

2．收尾（稳定）状态

当 $a=0$ 时速度达到最大（收尾）值 $v_m$。常见两类：

情景受力平衡式收尾速度 $v_m$
水平导轨，恒力 $F$ 拉，无摩擦$F = F_\text{安}$$v_m = \dfrac{F(R+r)}{B^2L^2}$
光滑斜面，恒力 $F$ 沿斜面$F = mg\sin\theta + F_\text{安}$$v_m = \dfrac{(F-mg\sin\theta)(R+r)}{B^2L^2}$
竖直下落，只受重力（无外力）$mg = F_\text{安}$$v_m = \dfrac{mg(R+r)}{B^2L^2}$
⚠️ 收尾的本质：加速度为零≠速度为零，而是速度达到稳定值，此后匀速运动，电流恒定。
例题：水平光滑导轨间距 $L=0.5\,\text{m}$，电阻 $R=1\,\Omega$，棒质量 $m=0.1\,\text{kg}$，匀强磁场 $B=1\,\text{T}$ 垂直，恒力 $F=0.5\,\text{N}$ 拉棒（棒电阻不计）。求收尾速度 $v_m$ 与收尾时热功率。

解：收尾时 $F=F_\text{安}=BIL=\dfrac{B^2L^2v_m}{R}$，故 $v_m=\dfrac{FR}{B^2L^2}=\dfrac{0.5\times1}{1^2\times0.5^2}=2\,\text{m/s}$。

电流 $I=\dfrac{BLv_m}{R}=\dfrac{1\times0.5\times2}{1}=1\,\text{A}$，热功率 $P_\text{热}=I^2R=1^2\times1=1\,\text{W}$（等于拉力功率 $Fv_m=0.5\times2=1\,\text{W}$）。

5电荷量与位移

通过回路某截面的电荷量 $q = \bar I\,\Delta t$，其中平均电流 $\bar I = \dfrac{\bar E}{R+r} = \dfrac{\Delta\Phi}{(R+r)\Delta t}$，故

$$q = \frac{\Delta\Phi}{R+r} = \frac{B\,L\,x}{R+r}$$

$x$ 为棒在垂直磁场方向的位移。由此得位移与电荷量的关系：

$$x = \frac{q(R+r)}{B\,L}$$
📌 关键结论：电荷量 $q$ 只与磁通量变化量 $\Delta\Phi$和总电阻有关，与运动快慢、时间无关。测 $q$ 即可求位移。

6能量转化

导体棒在磁场中运动，外力（或其他力）做功，一部分转化为棒的动能，另一部分克服安培力做功转化为焦耳热。

$$W_\text{牵} = \Delta E_\text{k} + Q$$
$$Q = W_\text{克安} = \int F_\text{安}\,dx$$
📌 三条能量关系：
  • 克服安培力做的功 $=$ 回路产生的焦耳热：$W_\text{克安}=Q$；
  • 安培力的功率 $P_\text{安}=F_\text{安}v$（阻力，做负功）；
  • 匀速时：拉力功率 $=$ 热功率，即 $Fv = I^2(R+r)$。
⚠️ 注意：安培力是阻力时做负功，能量"凭空消失"的部分全部变成内能（焦耳热），符合能量守恒。

7转动切割与有效长度

1．转动切割电动势

棒绕一端转动，线速度从 0 线性增大到 $\omega L$，取平均 $v_\text{均}=\dfrac{\omega L}{2}$：

$$E = B\,L\,v_\text{均} = \frac12\,B\,\omega\,L^2$$

若棒绕距一端 $a$ 处转动（两端到轴距离 $a$、$b$），则 $E=\dfrac12 B\omega(a^2+b^2)$。

2．有效长度典型情形

导体形状有效长度 $L_\text{有效}$
直棒，速度垂直棒棒长 $L$
弯折导体（∠ 形）两端点在垂直速度方向投影的距离
棒与速度成 $\theta$ 角$L\sin\theta$
圆形线圈一边切割切割边在垂直速度方向投影
棒不全在磁场内磁场内部分的长度
⚠️ 易错：只有处在磁场中且垂直于速度方向的那段导体才计入有效长度。磁场外的部分不产生电动势。

8高考经典

例 1（多选）：如图所示，光滑平行金属导轨间距 $L$，电阻不计，左端接电阻 $R$，匀强磁场 $B$ 垂直导轨平面。质量为 $m$ 的棒 ab 初速 $v_0$ 向右运动，不计摩擦。则（　）

A. 棒做匀减速运动 —— 错：安培力 $F_\text{安}=\dfrac{B^2L^2v}{R}$ 随 $v$ 减小而减小，加速度减小，为变减速。

B. 棒最终静止 —— 对：安培力持续阻碍运动，动能全部转化为焦耳热。

C. 全过程产生焦耳热 $Q=\dfrac12 mv_0^2$ —— 对：动能全部转化为热。

D. 通过电阻的电荷量 $q=\dfrac{BLx}{R}$ —— 对：由 $q=\dfrac{\Delta\Phi}{R}=\dfrac{BLx}{R}$。

答案：BCD

例 2：上题中若棒从静止开始受恒定拉力 $F$ 作用，求稳定速度 $v_m$ 及此状态下拉力功率。

解：稳定时 $F=F_\text{安}=\dfrac{B^2L^2v_m}{R}\Rightarrow v_m=\dfrac{FR}{B^2L^2}$。

拉力功率 $P=Fv_m=\dfrac{F^2R}{B^2L^2}$，且等于热功率 $I^2R$。
