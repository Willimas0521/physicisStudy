▶知识框架

双棒模型：两根导体棒在同一对平行导轨上运动，各自切割磁感线产生电动势，二者在回路中反向串联。

📌 核心特征：
  1. 总电动势取决于两棒相对速度：$E_\text{总}=BL|v_1-v_2|$；
  2. 两棒速度相等（共速）时，回路电动势为零、电流为零——这是双棒模型最重要的临界；
  3. 无外力时，安培力是系统內力，两棒系统动量守恒，最终共速；
  4. 有外力拉动其中一棒时，系统有恒定加速度，稳定后两棒加速度相同、电流恒定。

💡 本页为自由学习模式，所有小节都能直接查看；每节底部配小测验，仅作自我检测。

1等效电源

两棒切割电动势分别为 $E_1=BLv_1$、$E_2=BLv_2$。在闭合回路中两电源反向串联（取决于回路绕行方向），总电动势由相对速度决定：

$$E_\text{总} = B\,L\,|v_1 - v_2|$$

回路电流（总电阻 $R_\text{总}$，含两棒电阻与外电阻）：

$$I = \frac{E_\text{总}}{R_\text{总}} = \frac{B\,L\,|v_1 - v_2|}{R_\text{总}}$$
📌 最关键结论：当 $v_1 = v_2$（两棒共速）时，$|v_1-v_2|=0$，回路电动势为零、电流为零，安培力消失。因此双棒模型必然向"共速"演化。
⚠️ 方向判断：电流方向由"快的那根棒"决定——它的电动势更大，在回路中占主导；慢棒相当于被"反充电"。

2双棒模型分类

双棒按"导轨间距（棒长）是否相等、是否有外力、初速度如何"可分成几类。先建立分类总览，再逐一突破。

模型关键条件最终状态
等距 + 无外力 + 有初速度$L_1=L_2$，系统无外力，至少一棒有初速动量守恒 → 共速，电流为零
等距 + 有外力 + 无初速度$L_1=L_2$，恒力拉一棒，从静止开始整体匀加速，稳定后加速度相同、电流恒定
不等距双棒$L_1\neq L_2$（或导轨间距不同）共速时仍有电动势/电流，动量不守恒

1．等距双棒 + 无外力 + 有初速度

两棒等长 $L$，水平光滑，系统不受外力；设棒1 有初速 $v_0$、棒2 静止（一般情形用各自初速）。两棒反向串联，总电动势

$$E_\text{总}=B\,L\,|v_1-v_2|$$

回路电流使快棒受安培阻力、慢棒受安培动力，两棒速度趋于接近；又因安培力是系统内力，系统动量守恒：

$$m_1 v_{10}+m_2 v_{20}=(m_1+m_2)\,v_\text{共}$$

当 $v_1=v_2=v_\text{共}$ 时相对速度为零，电流为零、安培力消失，演化停止。系统动能损失全部变为焦耳热：

$$Q=\left(\frac12 m_1 v_{10}^2+\frac12 m_2 v_{20}^2\right)-\frac12(m_1+m_2)v_\text{共}^2$$
📌 特例：$m_1=m_2=m$、$v_{20}=0$ 时，$v_\text{共}=\dfrac{v_0}{2}$，$Q=\dfrac14 m v_0^2$。

2．等距双棒 + 有外力 + 无初速度

对棒1 施恒定外力 $F$，两棒均从静止开始（无初速度）。整体合外力为 $F$，系统加速度

$$a_\text{系}=\frac{F}{m_1+m_2}$$

起始两棒同速（都为 0），无电流；棒1 被拉得快于棒2，出现速度差，产生电流：棒1 受安培阻力、棒2 受安培动力。经历短暂变加速后，两棒加速度均趋于 $a_\text{系}$，速度差 $\Delta v$ 恒定，电流恒定：

$$I=\frac{m_2\,F}{B\,L\,(m_1+m_2)}$$
⚠️ 注意："无初速度"情形最终不是共速，而是两棒以相同加速度 $a_\text{系}$ 匀加速、电流恒定不为零——与"无外力有初速度"的共速结局正好相反。

3．不等距双棒

两棒切割长度（或所在导轨间距）不同，$L_1\neq L_2$，电动势分别为 $E_1=BL_1v_1$、$E_2=BL_2v_2$，总电动势

$$E_\text{总}=|B\,L_1 v_1-B\,L_2 v_2|$$

两棒所受安培力 $F_1=BIL_1$、$F_2=BIL_2$ 大小不相等，故安培力不是等大反向内力，系统动量不守恒。最本质的区别在于：

📌 核心区别：等距双棒共速（$v_1=v_2$）时电流为零；而不等距双棒即使共速，只要 $L_1\neq L_2$，仍有电动势 $E_\text{总}=B|L_1-L_2|\,v\neq0$，电流不为零，不会停在共速状态。

处理不等距模型，一般对每根棒分别列牛顿第二定律/动量定理，再结合电流关系 $I=\dfrac{E_\text{总}}{R_\text{总}}$ 联立求解，不能套用等距的"动量守恒+共速"结论。

3无外力双棒 · 动量守恒

光滑水平导轨、系统不受外力时，两棒所受安培力等大反向，是系统内力，故两棒系统动量守恒。

$$m_1 v_{10} + m_2 v_{20} = (m_1 + m_2)\,v_\text{共}$$

较快的棒受安培阻力减速，较慢的棒受安培动力加速，直到共速$v_\text{共}$，此时电流为零、演化停止。

能量与焦耳热

系统动能损失全部转化为焦耳热：

$$Q = \left(\frac12 m_1 v_{10}^2 + \frac12 m_2 v_{20}^2\right) - \frac12 (m_1+m_2)v_\text{共}^2$$
📌 特例（一棒初速为 0）：若 $v_{20}=0$，则 $v_\text{共}=\dfrac{m_1 v_{10}}{m_1+m_2}$，$Q=\dfrac12 m_1 v_{10}^2-\dfrac12(m_1+m_2)v_\text{共}^2=\dfrac{m_1m_2}{2(m_1+m_2)}v_{10}^2$。
例题：质量均为 $m$ 的两棒，棒1 初速 $v_0$、棒2 静止，导轨光滑、电阻不计（总阻 $R$）。求共速速度 $v_\text{共}$ 与产生的总焦耳热 $Q$。

解：动量守恒 $mv_0 = 2m\,v_\text{共}\Rightarrow v_\text{共}=\dfrac{v_0}{2}$。

$Q=\dfrac12 mv_0^2-\dfrac12(2m)\left(\dfrac{v_0}{2}\right)^2=\dfrac14 mv_0^2$。

4有外力双棒

若对棒1 施加恒定外力 $F$（棒2 无外力），两棒始终受等大反向安培力，整体受合外力 $F$。

1．整体加速度

$$a_\text{系} = \frac{F}{m_1 + m_2}$$

2．稳定状态（加速度相同）

经历短暂变加速后，两棒加速度趋于相同 $a=a_\text{系}$。对两棒分别列式：

$$F - B\,I\,L = m_1 a,\qquad B\,I\,L = m_2 a$$

消去 $a$ 得恒定电流：

$$I = \frac{m_2\,a}{B\,L} = \frac{m_2\,F}{B\,L\,(m_1+m_2)}$$
📌 稳定时的重要性质：两棒加速度相同 $\Rightarrow$ 速度差 $\Delta v=v_1-v_2$ 保持恒定，故电流 $I=\dfrac{BL\Delta v}{R_\text{总}}$ 恒定，安培力恒定。
⚠️ 与"无外力"的区别：无外力→最终共速、电流为零；有外力→最终两棒以相同加速度匀加速、电流恒定不为零。

5电荷量与能量

1．电荷量

通过回路的电荷量只取决于磁通变化量与总电阻：

$$q = \frac{\Delta\Phi}{R_\text{总}} = \frac{B\,L\,\Delta x}{R_\text{总}}$$

$\Delta x$ 为两棒间距离的变化量。对单棒用动量定理 $B\,I\,L\,\Delta t=\Delta p$ 可得 $q=\dfrac{\Delta p}{B\,L}$（$\Delta p$ 为该棒动量变化量）。

2．能量

情形能量关系
无外力初动能 $\to$ 共速动能 $+$ 焦耳热 $Q$
有外力拉棒1拉力做功 $W_F = \Delta E_\text{k} + Q$
📌 解题套路：① 先由动量守恒（无外力）或整体牛顿第二定律（有外力）求末速度/加速度；② 再求电荷量、焦耳热。

6高考经典 · 双棒切割

【高考真题·例 1】双棒无外力·动量守恒（2021·全国甲·改编）

两根平行光滑金属导轨间距 $L$，电阻不计，固定在水平面内。两导体棒 a、b 质量均为 $m$，电阻均为 $R$，垂直跨放导轨上。初始 b 静止，a 以 $v_0$ 向右运动。求：(1) 最终共同速度 $v$；(2) 全过程中产生的总焦耳热 $Q$。

解：(1) 系统水平方向不受外力，动量守恒：$mv_0 = 2mv \Rightarrow v = \dfrac{v_0}{2}$。

(2) 由能量守恒：初动能 $\dfrac12 mv_0^2$，末动能 $\dfrac12(2m)v^2=\dfrac14mv_0^2$，故 $Q=\dfrac12mv_0^2-\dfrac14mv_0^2=\dfrac14mv_0^2$。

【高考真题·例 2】双棒有外力·恒定加速度（2020·山东·改编）

两平行导轨，间距 $L$，电阻不计。导体棒 a、b 质量分别为 $m_a$、$m_b$，电阻不计。a 受恒定外力 $F$ 向右，b 受恒定外力 $2F$ 向右；初始均静止。求 $t$ 时刻两棒加速度及安培力。

解：将两棒视为整体，合外力 $3F$，整体加速度 $a=\dfrac{3F}{m_a+m_b}$（即两棒共同加速度）。

对 a 隔离：$F-F_A=m_a a$；对 b 隔离：$2F+F_A=m_b a$。联立得安培力 $F_A=\dfrac{(m_b-2m_a)F}{m_a+m_b}$。

讨论：当 $m_b=2m_a$ 时 $F_A=0$，两棒无需电磁耦合即同步加速。
