1磁场范围为圆形

1．题型特征

已知粒子进、出磁场的速度方向，要求出圆形磁场区域的最小面积。一般方法是：先确定带电粒子在磁场区域的入射点和出射点，连接这两点即得到磁场区域的直径；根据图中几何关系得到磁场区域直径的数值，然后利用面积公式得出圆形磁场区域的最小面积。

2．解题步骤

  1. 平移速度，求速度偏转角 $\theta$（圆心角）：将入射、出射速度平移至同一点，两速度方向的夹角即偏转角 $\theta$，也等于粒子在磁场中运动的圆心角。
  2. 由圆心角与弦切角的关系求弦切角 $\alpha$：
    $$\theta = 2\alpha$$
  3. 代入弦长公式，求弦长 $L$：已知半径 $r=\dfrac{mv}{qB}$ 与弦切角 $\alpha$，则
    $$L = 2r\sin\alpha$$
  4. 由直径算面积：弦长 $L$ 即最小圆形磁场的直径，故半径 $R=\dfrac{L}{2}$，最小面积为
    $$S_{\min} = \pi R^2 = \pi\left(\frac{L}{2}\right)^2 = \frac{\pi L^2}{4}$$
📌 核心结论：当入射点 $A$ 与出射点 $B$ 的连线恰好为所求圆形磁场的直径时，该圆面积最小——因为给定弦长，以该弦为直径的圆是包含该弦的最小圆。

2磁场范围为矩形

1．题型特征

粒子以某一速度（通常为垂直于某一边入射）进入矩形磁场，要求矩形磁场的最小面积。此类问题往往隐含“粒子不能穿出磁场侧边”的条件，或者是给定入射方向，求包含完整轨迹的最小矩形。

2．解题步骤

  1. 定轨迹：根据粒子的速度方向和磁场方向，确定粒子做圆周运动的轨迹圆心和半径 $R$。
  2. 找切点（宽度约束）：若粒子从矩形的一边中点垂直入射，为保证粒子不打到左右两侧壁，粒子轨迹的最高点（或最低点）必须与矩形的上下边界相切。此时矩形的最小宽度（直径）$d_{\min}=2R$。
  3. 定边界（长度约束）：粒子的入射点和出射点必须落在矩形的两条对边上。连接入射点和出射点，或找到轨迹两端的坐标极限，矩形的最小长度即为入射点与出射点在入射方向上的投影距离 $L_{\min}$。
    ⚠️ 特例（速度偏转）：若粒子垂直入射，偏转后切着邻边出去，则最小矩形边长为 $L_{\min}=R$，$d_{\min}=R$（即正方形边长 $R$，是“正方形的一半”情形）。
  4. 算面积：
    $$S_{\min} = L_{\min}\, d_{\min}$$
📌 口诀：宽看直径（相切），长看出射。

3磁场范围为树叶形（动态圆 / 旋转圆）

1．题型特征

粒子源发出大量同种带电粒子，速度大小相等、但方向在一定范围内变化，要求包含所有可能轨迹的最小磁场区域。所有可能的轨迹组合起来像一片叶子，故称“树叶形”（动态圆/旋转圆问题）。

2．解题步骤

  1. 定圆族：所有粒子速率相同，故在磁场中圆周运动的半径 $R$ 均相等。以发射点 $S$ 为基准，画出几个特殊方向的轨迹（如向左、向右、向上）。
  2. 找包络线（关键）：这些半径相同的圆的内公切线（或外公切线）构成了磁场的边界。
    • 若粒子向各个方向发射，最小磁场区域是以 $S$ 为圆心、$R$ 为半径的圆（最特殊情况）；
    • 若粒子只向某一侧发射（如从狭缝射出），最小磁场区域通常是一段圆弧加上两条切线。
  3. 定边界：
    • 直线边界：连接入射点 $S$ 与轨迹最远点（或速度反向延长线），该直线即为磁场的直线边界；
    • 曲线边界：以 $S$ 为圆心、$R$ 为半径作圆，该圆的一段弧即为磁场的曲线边界。
  4. 算面积：树叶形面积通常由一个扇形面积减去（或加上）一个三角形面积构成。
📌 口诀：半径相等画圆族，内外切线定轮廓。

4磁场范围为三角形

1．题型特征

要求包含粒子完整轨迹的最小三角形磁场区域。最常见的情况是求等腰直角三角形或等边三角形磁场的最小面积。

2．解题步骤

  1. 定轨迹与切点：画出粒子运动的轨迹圆。为使三角形面积最小，轨迹圆必须与三角形的三个顶点或三条边有特殊位置关系。常用模型：轨迹圆与三角形的两条直角边相切，且斜边刚好经过轨迹圆的直径端点。
  2. 找最小三角形（以等腰直角三角形为例）：

    设粒子从直角顶点 $C$ 入射，沿 $CB$ 方向；让轨迹圆与直角边 $AC$ 相切于点 $P$，与直角边 $BC$ 相切于点 $Q$。此时最小的等腰直角三角形以 $PQ$ 为一条直角边构造（或满足斜边长度等于 $2R$，即轨迹圆的直径）。

    $$\text{若轨迹半径为 } R \text{，则最小直角三角形的直角边长 } = 2R$$
  3. 通用解法（内切圆法）：寻找能包含这段圆弧的最小内接三角形。对于速度偏转角为 $\theta$ 的粒子，若要求最小等腰三角形，常利用正弦定理 $\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}$（其中外接圆半径需与 $R$ 相互转换）。
  4. 算面积：由所得边长直接计算三角形面积。
📌 口诀：轨迹圆内切三角，三边相切面积小。（通常是轨迹圆与三角形的两边相切，第三边限制出射。）
